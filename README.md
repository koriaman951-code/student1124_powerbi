# Student Performance Analysis — Power BI Dashboard

An interactive Business Intelligence (BI) dashboard built in **Microsoft Power BI Desktop** to analyze student academic performance, attendance, study habits, and demographic factors through dynamic visual reports and KPI summaries.

---

## Project Overview
This project transforms raw student performance records into an interactive Power BI report. It enables educators and analysts to explore exam scores, pass/fail distributions, subject-level trends, and key factors influencing student outcomes across different cohorts.

---

## Key Features
* **Data Cleaning & Transformation:** Cleaned, standardized, and formatted raw student records using **Power Query Editor** (handling missing values, data types, and column splits/merges).
* **Data Modeling:** Structured clean relationships across student, subject, and performance tables for accurate cross-filtering.
* **DAX Calculations:** Built custom DAX measures and KPI cards to track average scores, pass rates, top performers, and overall student counts.
* **Interactive Visuals & Slicers:** Designed dynamic bar/column charts, distribution charts, summary tables, and slicers for filtering by gender, parental education, test preparation, attendance, or subject.
